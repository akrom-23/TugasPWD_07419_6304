A. Profil Saya

Perkenalkan, nama saya Akrom Taufiqurrozak, mahasiswa Sistem Informasi di Fakultas Ilmu Komputer. Saat ini saya berfokus memperdalam pemahaman di bidang web development, manajemen basis data, serta analisis kebutuhan sistem. Saya memiliki rasa ingin tahu yang tinggi terhadap perkembangan teknologi digital dan selalu antusias untuk mengimplementasikan teori perkuliahan ke dalam proyek nyata yang solutif.

Website ini disusun sebagai portofolio pribadi berbasis HTML5 murni guna memahami fundamental dari pemetaan elemen web semantik. Seluruh komponen mulai dari navigasi, tabel, hingga formulir interaktif dibuat secara terstruktur sesuai standar perkuliahan. Melalui pengerjaan tugas ini, saya belajar bagaimana membangun fondasi situs yang rapi sebelum nantinya dikembangkan lebih jauh menggunakan style CSS maupun script interaktif.
